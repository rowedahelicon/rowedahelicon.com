Colophon

This website was created by paw with HTML, CSS, and a home-made static generator built with PHP. It was written using VSCodium, and is maintained via WinSCP. Tailwind CSS is used as a the CSS framework.

It is currently hosted via DigitalOcean. However, I do not support their AI priorities, and thus, I intend to eventually move to a new host.

This website features no tracking, no advertisements, and as little javascript as needed. You can view the source code for the site itself and my static builder on my Github page.

Like most of my web projects, this website is designed to be viewed by anyone. It was built to meet WebAIM's standards for web accessibility, and features lightweight and efficient coding practices.

My supported ideas, technologies, and ethos.

I believe in digital freedom. The internet is a place where people can bask in the collection of all of humanity's knowledge. It is a place meant to explore and challenge ideas, find those who match our weird, and ultimately shape ourselves freely into who we wish to be.

I believe that the internet is humanity's greatest culture, and it has never been properly viewed, understood, or respected as one. I feel this is a tragedy that betrays the entire collective efforts of everyone who has ever given anything to this world.
